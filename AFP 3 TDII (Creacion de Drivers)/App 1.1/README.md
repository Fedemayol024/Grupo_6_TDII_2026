# App 1.1 - Grupo 6 - TDII 2025

Secuencia de leds onboard (verde -> azul -> rojo, 200 ms ON / 200 ms OFF).
Placa: NUCLEO-F429ZI

## Como abrirlo en STM32CubeIDE
1. Descomprimir el zip.
2. En STM32CubeIDE: File -> Import -> General -> Existing Projects into Workspace.
3. Seleccionar la carpeta App_1_1_Grupo_6_2025 y Finish.
4. Compilar con el martillo (Build) y grabar con el play verde (Run).

El codigo de la aplicacion esta en Core/Src/main.c
