# App 1.1 (modificada) - AFP 4 - Grupo 6 - TDII 2025

Secuencia de leds onboard (verde -> azul -> rojo) pero ahora usando
retardos NO bloqueantes en vez de HAL_Delay.

Driver de delays: Drivers/API/inc/header.h y Drivers/API/src/fuente.c

## Como abrirlo
1. Descomprimir.
2. STM32CubeIDE: File -> Import -> General -> Existing Projects into Workspace.
3. Seleccionar la carpeta App_1_4_Grupo_6_2025 -> Finish.
4. Build (martillo) y Run (play verde) con la placa conectada.
